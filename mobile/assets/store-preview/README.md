# App Store Preview Assets

Capture these screens from the iOS Simulator or a physical device for App Store Connect.

## Recommended screenshots (1290 × 2796 — iPhone 6.7")

1. **Onboarding** — first slide with heart
2. **Login** — welcome back screen
3. **Home** — dashboard with heart + risk badge
4. **Health** — vitals and progress bar
5. **Learn** — article list
6. **Chat** — doctor messages
7. **Profile** — user card + settings entry

## How to capture

```bash
cd mobile
npx expo start
# Press i for simulator
# Cmd+S in Simulator saves screenshot to Desktop
```
